# BINTER SPACE (빈터공간)

> 여백에서 시작되는 주거공간 — Residential Interior Design Studio

고급 주거 인테리어 브랜드 **빈터공간(BINTER)** 의 공식 홈페이지입니다.

## 🏛 구조

```
binter-space/
├── index.html          # 메인 페이지
├── about.html          # 브랜드 소개 · 디자이너
├── portfolio.html      # 프로젝트 아카이브
├── process.html        # 디자인 프로세스 (4단계)
├── journal.html        # 블로그 · 인사이트
├── contact.html        # 상담 신청 폼
└── assets/
    └── shared.css      # 공통 스타일
```

## 🎨 디자인 컨셉

- **철학**: 여백(emptiness)과 침묵(silence)을 담는 공간
- **톤**: 웜 뉴트럴 베이스 (#f5f2ed) + 잉크 블랙 (#1a1816) + 브론즈 액센트 (#8b6f47)
- **타이포그래피**:
  - Display: Cormorant Garamond (이탤릭 강조)
  - Body (EN): Archivo Light
  - Body (KR): Nanum Myeongjo (명조체)

## 🚀 GitHub Pages 배포 방법

1. 이 폴더를 GitHub 저장소에 업로드
2. 저장소 **Settings → Pages** 이동
3. Source를 `main` 브랜치 / `/ (root)` 로 설정
4. 저장 후 `https://[username].github.io/[repo-name]/` 로 접속

## ✏️ 커스터마이징 포인트

실제 운영 시 수정이 필요한 항목입니다.

- `contact.html`: 이메일, 전화번호, 주소
- 모든 페이지 footer: 연락처 정보
- `portfolio.html`: 실제 프로젝트 사진 교체
- `about.html`: 디자이너 이름 · 약력 · 수상 이력
- `journal.html`: 실제 블로그 글로 교체
