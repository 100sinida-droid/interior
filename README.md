# BinteoSpace (빈터공간)

> 여백에서 시작되는 주거공간 — Residential Interior Design Studio

고급 주거 인테리어 브랜드 **BinteoSpace 빈터공간** 의 공식 홈페이지입니다.

## 🏛 구조

```
binteo-space/
├── index.html          # 메인 페이지
├── about.html          # 브랜드 소개 · 디자이너
├── portfolio.html      # 프로젝트 아카이브
├── process.html        # 디자인 프로세스 (4단계)
├── journal.html        # 블로그 · 인사이트
└── contact.html        # 인스타그램 DM 문의 안내
```

각 HTML 파일은 **모든 CSS를 내장**하고 있어 독립적으로 동작합니다.
외부 스타일시트 의존성이 없어서 어떤 환경에서도 깨지지 않습니다.
